# rmw_mdds Full Parity Acceptance Matrix

Audit date: 2026-07-03
Change: `complete-rmw-mdds-full-parity-acceptance`

This matrix is the current acceptance boundary for the broad "perfect/all ROS 2 middleware features" goal. A `proven` row has current code, test, contract, or board evidence. An `incomplete` row blocks goal completion until it has a RED test/contract, implementation, runtime evidence, or explicit user acceptance as out of scope. This audit does not accept any unsupported row as out of scope yet.

## Current Completion Decision

The full persistent goal is not finished yet. The current code and prior tasks prove a strong scoped ROS 2 over `rmw_mdds_cpp` and MDDS runtime, but the universal "perfect/all ROS 2 middleware features" objective remains blocked by incomplete rows for generalized loaned-message shapes, signed/transport security semantics, MDDS/broker network-flow metadata, and upstream handoff.
